# How Continuity reached Core 0.2

Public development summary, 19 September 2026. This is a readable history and direction-of-travel note, not the internal task roadmap or a promise of release dates.

| Stage | What changed | Current standing |
|---|---|---|
| Founding principles — August 2026 | Defined bounded authority, typed responsibility, succession and evidence-relative answers. | These ideas informed the current reference contracts and runnable evaluation. |
| Core 0.1 — foundation | Demonstrated deterministic decisions, retained history, receipts, replacement and enduring duties in a controlled reference environment. | Founder accepted; the selected foundation roadmap is closed. |
| Core 0.2 — integration learning | Security-review experiments exposed the need for explicit executor acknowledgments and one common engine. | Core 0.2.2 and approved executor profiles implemented and demonstrated locally. |
| Core 0.2 — operator workflow | Added saved progress, bounded handover, current revocations, source verification, reporting-key replacement and local recovery. | Selected reference-development roadmap complete; evidence remains scoped to its tested environment. |
| Evaluation and presentation | Curated a runnable synthetic tutorial, permission comparison, developer example and recorded Linux guide; added the visual demonstration. | Accepted presentation; the first public evaluation release is authorized. |

## What comes next is a discussion

Future public proposals can use the [RFC process](RFC.md). Vigil/OS enforcement, longer-lived agents and privacy techniques such as zero-knowledge proofs are research directions, not implemented features or an approved delivery schedule. No hardware security, universal containment, production readiness or cryptographic breakthrough is claimed.

The enduring priorities are separation of identity/execution/authority/obligation; recovery that preserves revocations, consumed limits and unresolved outcomes; protected interfaces for untrusted requests; explicit enforcement coverage; and deterministic privileged decisions.
