## Explain saved output

```sh
continuity-explain --help
continuity-explain --surface gateway --code GATEWAY_CONFIGURATION_UNAVAILABLE
continuity-explain --surface mcp < saved-error.json
```

Keep the original output and exit code. The command explains one untrusted saved record; it does not authenticate it, inspect live state, verify a proof, start a command or authorize a retry. Unknown or ambiguous formats are refused. Input is bounded and duplicate JSON keys are refused; extra private payload fields are not printed. Historical source families require their explicitly named format and are not new installed runtime backends. A gateway startup explanation does not establish that nothing started or that restarting is safe.

```js
import { explainCode } from '@ramex-labs/continuity/messages';
console.log(explainCode('gateway', 'GATEWAY_CONFIGURATION_UNAVAILABLE'));
```
