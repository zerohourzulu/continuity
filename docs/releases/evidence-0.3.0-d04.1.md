# Continuity evidence — private D04 integration

This private package joins the investigation-disposition engine with the existing continuing-case integrations. It is not published. Use Node 22.18+ on the 22.x line or Node 24.x. All four D04 packages use version `0.3.0-d04.1` and share one Core.

An explicitly activated investigation may complete or escalate under its local rules. Later relevant evidence requires review; an accepted contest remains outstanding. Local completion never proves an outside result, restores a revoked permission, or refreshes spent allowance. Trusted host configuration, local declared-root trust and finite storage still apply.

The Core package exposes host-only `@ramex-labs/continuity/duties` preparation, recording and inspection. Signing keys, policy selection, source/report verification and current runtime choice belong to the trusted host. An agent tool request does not receive those powers. Existing remote, MCP and LangChain tools keep their execution and recovery contract.

Install the exact private four-package tuple with the source tree's `tools/duty-release/install.mjs`. The earlier SDK directories and release tools remain historical. Publication and final maturity review are separate decisions.
