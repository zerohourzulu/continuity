# Explain a saved record in plain language

Run `node messages/explain.mjs --help` for the available source families and exact input shape. The renderer explains one saved JSON record. It does not authenticate a record, check a proof or authorize a retry. Existing machine codes, envelopes, cause fields and retry policy remain unchanged.

The original forty-row catalogue has thirteen default human displays and twenty-seven explicit saved-record renderer routes. Further deduplication and source-family cleanup are included in additional.json. The accepted source edition recorded 116 focused checks, 46 module parse checks and 15 targeted wording checks. Later Core-reader follow-up added six checks, including the plain-language explanation of a fence. These are retained local results, not new browser/MCP/usability measurements.

Public command/tutorial/browser wording is wired into this source release. [Other source families](../research/messages/README.md) are separately preserved for inspection; their copies are not an upgrade of historical proof kits or installed npm versions. A supplied failure record does not by itself justify rerunning a command.
