# Continuity — current setup

Use the [complete package and quickstart](https://github.com/zerohourzulu/continuity/blob/main/docs/QUICKSTART.md), not this document-download folder or the historical website/source subset.

The current onboarding edition supports Node22.18+ within22.x,24.x and26.x on macOS/Linux. The recorded reader needs Node alone. `node tools/setup.mjs` installs locked dependencies without global pnpm; `node tutorial/start.mjs` generates and inspects a fresh synthetic case. Run these from the complete package directory.
