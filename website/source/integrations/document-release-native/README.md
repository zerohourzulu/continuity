# Linux document-release syscall boundary

Trusted broker code loads `index.cjs`. Build on the selected Linux guest with `sh build.sh`, existing C++17 compiler and `/usr/include/node/node_api.h` (`NODE_INCLUDE_DIR` can select installed headers). No npm package, node-gyp, helper process or worker thread is involved. macOS refuses loading; there is no fallback publication mechanism. The binary is a local build product, not a committed portable binary.

All APIs below are synchronous. Root owns running the broker and bounded Linux demonstration. This binding enforces filesystem and transport mechanics; the application must supply deterministic current authority, the exclusive case mutex, verified manifests/content, admission/attempt persistence and the one-use invocation boundary. Never invoke publication from a worker or competing writer.

| API | Result and contract |
| --- | --- |
| `readFile(rootDirectory, relativePath, maxBytes)` | `{data:Buffer, uid,gid,mode,nlink,size,device,inode,type}`. Mode is permission/special bits (`&07777`). Maximum `maxBytes` is 4 MiB, matching the bounded original-attempt history artifact. Requires regular singly linked file, no ACL, bounded stable read. Caller checks expected owner/mode/digest. |
| `inspectDirectory(rootDirectory, relativePath)` | Same metadata (without data), plus lexically sorted `children` strings, maximum 128. Directory must be protected. |
| `publishDirectory({rootDirectory,stageName,destinationName,brokerUid,recipientGid})` | `{published:true,durable:true}` after rename and both parent flushes. `rootDirectory` is the fixed data directory, normally `/srv/continuity-lab/data`. Both names are 64 lowercase hex characters. `stage/<stageName>` moves to `inbox/<destinationName>`. |
| `acquireLock(absolutePath)` | Opaque process-held exclusive, nonblocking `flock` handle, with CLOEXEC. File must be broker-owned regular 0600/nlink1; creates exclusively by pathname semantics without following symlinks, and flushes file/parent. Another open description cannot acquire it concurrently. |
| `releaseLock(handle)` | Closes descriptor. Neither release nor finalization unlinks the lock inode. Keep handle strongly referenced for the broker lifetime. |
| `hardenProcess()` | Sets and verifies `no_new_privs=1`, dumpability=0. Launcher still owns identities, capability sets, supplementary groups, procfs and descriptor sanitation. Call before loading secrets. |
| `listen(absoluteSocketPath, options={})` | Opaque AF_UNIX SOCK_SEQPACKET nonblocking listener, with SO_PASSCRED and CLOEXEC. Options `backlog=16` (1–64), `maxClients=32` (1–128), `timeoutMs=2000` (1–30000). Does not overwrite/unlink an existing socket. Parent is protected; socket mode0666. |
| `poll(listener)` | Nonblocking array of `{connection,uid,gid,pid,data:Buffer}`. Credentials come from exactly one kernel SCM_CREDENTIALS record. Invalid packets/connections close without dispatch. Schedule polling at a bounded interval (e.g. 10ms) on the broker event loop. |
| `reply(connection, BufferOrString)` | One bounded UTF-8 response, then closes, including on send failure. Never blocks waiting for a reader. |
| `closeConnection(connection)` / `closeListener(listener)` | Idempotent descriptor closure. Listener closes its clients; no socket pathname unlink. Trusted launcher may remove a verified stale socket only while holding the case lock. |
| `connectClient(path, timeoutMs=2000)` | Client-only connection handle; useful for retaining A's already-open connection before replacement. |
| `clientSend(connection, BufferOrString)` | Exactly one request on the client handle; nonblocking send. |
| `clientReceive(connection, timeoutMs=2000)` | Client-only bounded blocking receive, returning reply Buffer and closing. |
| `sendRequest(path, BufferOrString, timeoutMs=2000)` | Client-only connect/send/receive convenience, returning reply Buffer. Do not call from the broker event loop. |

Every absolute root/lock/socket parent is walked from `/` with no symlink following, root-or-effective-UID ownership, no group/world write, and no access/default ACL. A protected root can be a separately mounted filesystem. Relative opens then require `openat2` with `RESOLVE_BENEATH | RESOLVE_NO_SYMLINKS | RESOLVE_NO_MAGICLINKS | RESOLVE_NO_XDEV`; intermediate relative directories receive the same ownership/write/ACL checks. Thus `/tmp` is deliberately unsuitable as a test ancestor; use an administrator-prepared private directory under `/srv` or a safe home.

Publication requires non-root effective UID equal to `brokerUid`, an ext4-family filesystem magic, and stage and inbox on the root's device with mount crossings prohibited. Linux reports the same magic for ext2/ext3/ext4; the trusted launcher must separately verify the selected mount's actual filesystem type is ext4 (for example from mountinfo) before starting the broker. Stage must be broker UID / effective GID /0700, inbox broker UID /recipient GID /0750. Prepared directory must be broker UID /recipient GID /0750, nlink2 and exactly `document.bin` and `publication.json`. Both files require broker UID /recipient GID /0440, nlink1, no ACL, positive bytes bounded by 65536 and 8192 respectively. The binding flushes both files, prepared directory and stage before `renameat2(RENAME_NOREPLACE)`, then both parents. It never copies, replaces or deletes a target. Exact expected content is an application check before this call under the same trusted broker boundary.

Errors have `errno` (numeric), `code` (`ENOENT`, `EEXIST`, `EACCES`, `ELOOP`, `EXDEV`, `EAGAIN`, `ENOSYS` or `NATIVE_BOUNDARY_ERROR`) and `publicationUncertain`. Publication sets uncertainty for **any** error once the rename syscall has been attempted, including refusal; successful return asserts only that these actual calls succeeded. It does not prove arbitrary power-loss durability or transaction atomicity with the event store. Before-call errors have `publicationUncertain=false`; application reservations and retained attempt evidence still govern disposition.

Ingress accepts one nonempty valid UTF-8 packet of at most16384 bytes per connection. `MSG_TRUNC`, `MSG_CTRUNC`, missing/multiple credentials, SCM_RIGHTS and unknown ancillary records are rejected. Every received descriptor is closed, including when other packet validation fails. A second ready receive (including a zero-length frame or EOF) is rejected before dispatch; clients must remain open waiting for their reply. Later frames never cause another dispatch: the connection is one-request, and reply/timeout closes it. No SO_PEERCRED dependence exists. PID is diagnostic only; the application compares message UID and claimed session to fixed enrollment on each dispatch. Idle/delivered clients expire during `poll`; `maxClients` bounds accepted descriptors and every poll performs bounded accept/receive work. This is bounded responsiveness, not a denial-of-service availability guarantee.

Use `node linux-check.cjs /srv/<administrator-prepared-broker-owned-empty-scratch>` as the non-root broker to run focused mechanics checks. It deliberately publishes harmless scratch bytes once. Root must explicitly select and run it on the disposable guest; it is not invoked by build/import and is not the full protected-service demonstration. The scratch path must be new/empty; the script preserves its outputs. It requires Node and Python3 already present, and tests successful publication/no overwrite, symlink/hardlink refusal, lock contention, credential ingress, extra/truncated packets, SCM_RIGHTS closure and idle expiry. Root owns retained Linux output and acceptance; no Linux results are claimed by source completion alone.
