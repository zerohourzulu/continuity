# Message source-family snapshots

The complete source-only families accompanying the accepted message cleanup are retained below source-families/. They preserve distinct dependency and source editions. The public command/browser changes are installed in the main source tree; these additional historical/reference copies are inspectable source, not installed runtime replacements.

Private machine paths, when present in old environment-bound helpers, are explicit publication placeholders. Provenance records each original and public hash. Raw runtime evidence, secret configuration and private records are excluded. Machine/refusal semantics and retry decisions are not rewritten by the prose cleanup. Run the main source's messages/explain.mjs only on a supported saved JSON shape.
